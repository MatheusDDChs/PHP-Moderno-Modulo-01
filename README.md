## ✨ Overview

PHP-Moderno-Modulo-01 is a versatile PHP project that combines educational content with practical web functionalities, making it ideal for learning and developing modern PHP applications.

**Why PHP-Moderno-Modulo-01?**

This project aims to enhance PHP development skills through real-world examples and modular design. The core features include:

- 🧩 **💻 Modular Architecture:** Organized code structure for easy learning and extension.
- 🌐 **🌟 API Integration:** Fetches real-time data like currency exchange rates for accurate financial calculations.
- 🚀 **🎯 Interactive Forms:** Supports user input for dynamic operations such as age calculation, currency conversion, and mathematical computations.
- 🛠️ **🔍 Demonstrates OOP Principles:** Models entities like companies with attributes and behaviors.
- 📅 **📈 Practical Examples:** Includes time, date, and number processing to illustrate core PHP functionalities.

## 🚀 Getting Started

### 📋 Prerequisites

This project requires the following dependencies:

- **Programming Language:** PHP
- **Package Manager:** Composer

### ⚙️ Installation

Build PHP-Moderno-Modulo-01 from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/MatheusDDChs/PHP-Moderno-Modulo-01
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd PHP-Moderno-Modulo-01
    ```

3. **Install the dependencies:**

**Using [composer](https://www.php.net/):**

```sh
❯ composer install
```

### 💻 Usage

Run the project with:

**Using [composer](https://www.php.net/):**

```sh
php {entrypoint}
```

### 🧪 Testing

Php-moderno-modulo-01 uses the {__test_framework__} test framework. Run the test suite with:

**Using [composer](https://www.php.net/):**

```sh
vendor/bin/phpunit
```
